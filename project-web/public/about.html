Tentang proyek

Dua sistem, satu katalog skincare.

[Nama Produk] adalah prototipe proyek kelompok untuk mata kuliah Kecerdasan Komputasional dan Natural Language Processing. Halaman ini masih memakai data dummy; model asli akan dihubungkan melalui API.

Komponen sistem

Kecerdasan Komputasional

Semantic Search

Pengguna mengetik kueri bahasa alami, lalu sistem mengembalikan produk yang paling relevan berdasarkan kemiripan makna.

  • Teks produk dipecah menjadi potongan (chunk)
  • Custom text embedding untuk kueri dan chunk
  • Peringkat dengan cosine similarity
  • Dibandingkan dengan baseline keyword search (BM25)
Natural Language Processing

Question Answering Ulasan

Pengguna memilih produk dan bertanya dalam bahasa Inggris. Sistem menjawab dari ulasan konsumen dan menampilkan kutipan sebagai bukti.

  • Retriever: BM25, pretrained, atau domain-adapted
  • Reader mengekstrak rentang jawaban dari ulasan
  • Bukti ulasan ditampilkan bersama skor relevansi
  • Menjawab "informasi tidak ditemukan" bila bukti kurang
